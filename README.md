# 🪐 逃離土星

刺牆賽跑類的 3D 跑酷小遊戲。第一關「家庭聚會」：酒鬼大叔在後面追、鬼媽媽揮熱熔膠條、終點有小屁孩大魔王。

- 玩：https://cooldragon313.github.io/saturnfamily/
- 帳號、金幣、排行榜跟「逃離大海嘯」共用（同一台伺服器 etfm.cooldragon313.workers.dev）
- 商店、換造型：https://cooldragon313.github.io/escapetsunamiformoney/island.html

## 怎麼更新

這個倉庫只放**產出的成品** `index.html`。原始碼在 escapetsunamiformoney 倉庫的 `race/race.src.html`
（跟海嘯島共用角色、畫風程式），用 `python tools/build_race.py` 產出 `index.html` 後複製到這裡再 push。
